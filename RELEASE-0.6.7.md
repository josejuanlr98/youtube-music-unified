# YouTube Music Unified 0.6.7

YouTube Music playback and Cast receiving for Steam Deck, with a polished fullscreen lyrics experience.

- Animated cover-colored fullscreen gradient with a darker readability layer.
- Cover-derived accent colors for the YouTube Music logo, source credit, and fullscreen UI.
- Synchronized lyrics when timing is available, plus automatic reading mode for plain lyrics.
- Cast-only mode without account setup, trusted-network discovery, queue controls, and optional notifications.
- Compact player and lyrics layouts tuned for Steam Deck and external displays.

## Install

Download `youtube-music-unified-0.6.7.zip`, install it through Decky's ZIP installer, and restart Decky if the previous version is still shown. Existing settings are preserved. The `-source.zip` archive is for development.

This release includes the implementation inspired by Artistro08's `decky-youtube-music-player` and `youtube-cast-receiver` projects. Their original projects remain credited in the README.
